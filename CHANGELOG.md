# Changelog

## [1.0.0] - Initial release

### Added
- **Project skeleton:** Node 20+ / Express backend with in-memory storage and a plain HTML/CSS/JS frontend served from `public/`.
- **Expense claims:** Submit, manage, and view expense claims.
- **USD conversion:** Expense amounts are converted to USD.
- **Approval tiers:** Claims are assigned an approval tier based on their USD amount.
